# RAG Chatbot with Local LLM (Ollama & LangChain)

Upload a PDF and ask questions about it. Answers are generated by a local LLM using only the PDF's content.

## Working Flow

```
PDF upload -> Load pages -> Split into chunks -> Embeddings -> Chroma DB
                                                                  |
Question -> Retriever (top 2 chunks) -> Prompt -> LLM -> Answer
```

1. **Upload**: the PDF is saved to a temporary file.
2. **Load**: `PyPDFLoader` reads the PDF page by page.
3. **Split**: text is cut into chunks (1000 chars, 200 overlap).
4. **Embed and store**: `nomic-embed-text` converts chunks to vectors, stored in Chroma.
5. **Retrieve**: the 2 chunks most similar to the question are fetched.
6. **Generate**: chunks + question go into a prompt, and `qwen:0.5b` writes the answer.

## Setup

```bash
pip install streamlit python-dotenv pypdf langchain-core langchain-community langchain-text-splitters langchain-ollama langchain-chroma

ollama pull nomic-embed-text
ollama pull qwen:0.5b
```

Optional `.env` (for LangSmith tracing only):

```
LANGCHAIN_API_KEY=your_key
```

## Run

```bash
streamlit run app.py
```

## Configuration

| Setting | Default |
|---|---|
| Chat model | `qwen:0.5b` |
| Embedding model | `nomic-embed-text` |
| Chunk size / overlap | `1000` / `200` |
| Retrieved chunks (`k`) | `2` |

## Notes

- `qwen:0.5b` is very small; use `llama3.2` or `qwen2.5:3b` for better answers.
